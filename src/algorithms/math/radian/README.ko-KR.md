# 라디안

[English](README.md) | [한국어](README.ko-KR.md)

라디안은 원의 반지름과 같은 길이의 호가 만드는 중심각을 1로 정한 각도 단위입니다. 반지름 1인 원에서는 호의 길이와 라디안 값이 같습니다.

한 바퀴는 `2π`라디안, 반 바퀴는 `π`라디안입니다. 도를 라디안으로 바꾸려면 `degrees×π/180`, 라디안을 도로 바꾸려면 `radians×180/π`를 계산합니다. 1라디안은 약 57.3도이며 아래 표는 대표 각도의 변환을 보여 줍니다.

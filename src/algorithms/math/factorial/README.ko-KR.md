# 팩토리얼

[English](README.md) | [한국어](README.ko-KR.md)

음이 아닌 정수 `n`의 팩토리얼 `n!`은 1부터 `n`까지의 정수를 모두 곱한 값입니다. `5!=5×4×3×2×1=120`이며 `0!=1`로 정의합니다.

반복문으로 누적 곱을 계산하거나 `n!=n×(n-1)!`이라는 재귀 관계를 사용할 수 있습니다. 결과가 빠르게 커지므로 JavaScript의 `Number`로 정확하게 표현할 수 있는 정수 범위를 고려해야 합니다. 원문 표에는 0부터 15까지의 결과가 있습니다.

## 예제·수식·시각 자료

```
5! = 5 * 4 * 3 * 2 * 1 = 120
```

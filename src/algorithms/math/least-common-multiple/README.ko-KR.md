# 최소공배수

[English](README.md) | [한국어](README.ko-KR.md)

두 정수의 최소공배수(LCM)는 두 수로 나누어떨어지는 가장 작은 양의 정수입니다. 4와 6의 공배수는 12, 24, 36 등이며 최소공배수는 12입니다.

최대공약수와의 관계로 `lcm(a,b)=|a*b|/gcd(a,b)`를 계산할 수 있습니다. 먼저 최대공약수로 나눈 뒤 곱하면 불필요하게 큰 중간 값을 줄일 수 있습니다. 0을 포함하는 경우는 보통 최소공배수를 0으로 정하는 별도 규칙을 사용합니다.

원문의 벤다이어그램은 여러 수의 공배수를 나타냅니다. 최대 5명에게 같은 수의 카드를 나눌 수 있게 하려면 2·3·4·5의 최소공배수인 60장이 필요합니다.

## 예제·수식·시각 자료

```
4, 8, 12, 16, 20, 24, 28, 32, 36, 40, 44, 48, 52, 56, 60, 64, 68, 72, 76, ...
```

```
6, 12, 18, 24, 30, 36, 42, 48, 54, 60, 66, 72, ...
```

```
12, 24, 36, 48, 60, 72, ....
```

```
lcm(a, b) = |a * b| / gcd(a, b)
```

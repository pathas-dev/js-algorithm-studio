# 소수 판별

[English](README.md) | [한국어](README.ko-KR.md)

소수는 1보다 큰 자연수 중 1과 자기 자신 외의 양의 약수가 없는 수입니다. 5는 소수이고 `6=2×3`은 합성수입니다. 0과 1은 소수가 아닙니다.

소수 판별은 입력이 소수인지만 판단하며 소인수 전체를 구하는 소인수분해와 다릅니다. 시험 나눗셈에서는 작은 약수부터 확인하며, 합성수의 약수 쌍 중 하나는 제곱근 이하이므로 그 범위까지 검사할 수 있습니다. 소수와 소수 판별은 암호학 등에서 활용됩니다.

# 올바른 괄호 검사

[English](README.md) | [한국어](README.ko-KR.md)

문자열이 `()`, `[]`, `{}`로 구성되었을 때 각 열린 괄호가 같은 종류의 닫힌 괄호와 올바른 중첩 순서로 대응하는지 검사합니다. `()`와 `()[]{}`는 올바르지만 `(]`는 올바르지 않습니다.

열린 괄호를 만나면 기대하는 닫힌 괄호를 스택에 넣습니다. 닫힌 괄호를 만나면 스택 꼭대기와 비교하고, 다르거나 스택이 비었다면 실패합니다. 입력 처리가 끝났을 때도 스택이 비어 있어야 합니다. 시간과 최악의 추가 공간은 `O(n)`입니다.

짝을 반복해서 찾아 제거하는 단순한 방식은 `O(n²)`이 될 수 있습니다. 스택은 가장 최근에 열린 괄호부터 닫혀야 하는 규칙을 직접 표현합니다.

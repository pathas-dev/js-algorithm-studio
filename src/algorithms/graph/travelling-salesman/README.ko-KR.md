# 외판원 문제

[English](README.md) | [한국어](README.ko-KR.md)

외판원 문제(TSP)는 도시들과 도시 사이의 거리가 주어졌을 때, 각 도시를 한 번씩 방문하고 출발 도시로 돌아오는 순환 경로 중 총거리가 가장 짧은 경로를 찾습니다.

도시는 정점, 이동 경로는 간선, 거리는 가중치로 나타낼 수 있습니다. 단순히 모든 정점을 방문하는 경로를 찾는 것이 아니라 거리의 합을 최소화해야 합니다. 원문의 그림에서는 빨간 점을 모두 연결하는 가장 짧은 순환 경로가 검은 선으로 표시됩니다.

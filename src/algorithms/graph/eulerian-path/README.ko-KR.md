# 오일러 경로

[English](README.md) | [한국어](README.ko-KR.md)

오일러 경로는 그래프의 모든 간선을 정확히 한 번씩 지나는 경로입니다. 시작점과 끝점이 같으면 오일러 회로라고 합니다. 모든 정점을 한 번씩 방문하는 해밀턴 경로와는 다릅니다.

간선이 있는 정점들이 연결된 무방향 그래프에서 모든 정점의 차수가 짝수이면 오일러 회로가 존재합니다. 홀수 차수 정점이 정확히 두 개라면 오일러 경로는 한 홀수 정점에서 시작해 다른 홀수 정점에서 끝납니다. 홀수 정점이 두 개보다 많으면 오일러 경로가 없습니다.

원문의 쾨니히스베르크 다리 그래프는 이 조건을 만족하지 않아 모든 다리를 정확히 한 번씩 건너는 경로가 없습니다.

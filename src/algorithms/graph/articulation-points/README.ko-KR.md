# 단절점

[English](README.md) | [한국어](README.ko-KR.md)

무방향 그래프에서 정점과 그 정점에 연결된 간선을 제거했을 때 연결 요소의 수가 증가하면 그 정점을 단절점이라고 합니다. 연결된 그래프에서는 하나의 정점 제거로 그래프가 둘 이상의 부분으로 나뉘는 경우입니다.

이미 분리된 그래프에서도 기준은 연결 요소 수의 증가입니다. 단절점은 네트워크에서 하나의 장애가 여러 구역을 분리할 수 있는 취약 지점을 나타내므로, 신뢰성 있는 네트워크를 설계할 때 유용합니다.

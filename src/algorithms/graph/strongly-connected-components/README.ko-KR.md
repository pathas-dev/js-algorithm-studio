# 강한 연결 요소

[English](README.md) | [한국어](README.ko-KR.md)

방향 그래프에서 모든 정점 쌍 사이에 양방향으로 도달 가능한 경로가 있으면 그래프가 강하게 연결되어 있다고 합니다. 전체 그래프가 강하게 연결되지 않아도 일부 정점들은 서로 양방향으로 도달할 수 있습니다.

강한 연결 요소는 이러한 성질을 만족하는 최대 정점 집합입니다. 간선 하나가 직접 양방향일 필요는 없고, 여러 간선을 거치는 경로가 양쪽 방향으로 존재하면 됩니다. 원문의 그림에서는 각 강한 연결 요소를 따로 표시합니다.

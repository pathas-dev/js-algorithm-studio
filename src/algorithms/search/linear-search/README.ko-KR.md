# 선형 탐색

[English](README.md) | [한국어](README.ko-KR.md)

선형 탐색은 배열의 원소를 처음부터 순서대로 목표와 비교합니다. 같으면 해당 위치를 반환하고, 끝까지 찾지 못하면 값이 없다고 판단합니다. 정렬되지 않은 배열에도 적용할 수 있습니다.

목표가 첫 원소이면 한 번의 비교로 끝나지만, 마지막에 있거나 없으면 모든 원소를 확인하므로 최악의 시간은 `O(n)`입니다.

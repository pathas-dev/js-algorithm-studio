# 트리의 깊이 우선 탐색 (DFS)

[English](README.md) | [한국어](README.ko-KR.md)

트리의 DFS는 루트에서 시작해 한 갈래를 끝까지 따라간 뒤 돌아와 다른 갈래를 탐색합니다. 재귀 호출이나 스택으로 돌아올 지점을 기억할 수 있습니다.

노드를 방문하는 시점에 따라 전위·중위·후위 순회가 달라집니다. 너비 우선 탐색은 같은 깊이의 노드들을 먼저 처리하지만, 깊이 우선 탐색은 하나의 하위 트리를 먼저 탐색합니다.

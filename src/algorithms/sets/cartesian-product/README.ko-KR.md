# 데카르트 곱

[English](README.md) | [한국어](README.ko-KR.md)

집합 `A`와 `B`의 데카르트 곱 `A×B`는 `a∈A`, `b∈B`인 모든 순서쌍 `(a,b)`의 집합입니다. 각 집합에서 하나씩 원소를 선택해 조합하되, 순서쌍에서 어느 집합의 원소인지 구분합니다.

원문은 `A={x,y,z}`, `B={1,2,3}`의 예를 그림으로 표현합니다. 가능한 쌍은 9개이며, 여러 집합에도 같은 정의를 확장할 수 있습니다.

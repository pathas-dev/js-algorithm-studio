# 조합 합 문제

[English](README.md) | [한국어](README.ko-KR.md)

중복되지 않는 양의 정수 후보들과 목표 합이 주어졌을 때 합이 목표가 되는 모든 고유한 조합을 찾습니다. 같은 후보를 여러 번 사용할 수 있지만, 선택 순서만 다른 결과는 중복 조합으로 취급합니다.

`[2,3,6,7]`에서 목표가 7이면 `[7]`과 `[2,2,3]`이 답입니다. 후보를 선택하며 남은 합을 줄이고, 합을 초과하면 해당 갈래를 중단하는 백트래킹으로 탐색할 수 있습니다. 다음 선택의 시작 위치를 유지하면 같은 조합을 다른 순서로 다시 만들지 않습니다.

## 예제·수식·시각 자료

```
Input: candidates = [2,3,6,7], target = 7,

A solution set is:
[
  [7],
  [2,2,3]
]
```

```
Input: candidates = [2,3,5], target = 8,

A solution set is:
[
  [2,2,2,2],
  [2,3,3],
  [3,5]
]
```

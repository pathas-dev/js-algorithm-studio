# 피셔–예이츠 셔플

[English](README.md) | [한국어](README.ko-KR.md)

피셔–예이츠 셔플은 유한한 수열을 무작위 순열로 바꾸는 알고리즘입니다. 남아 있는 원소 중 하나를 균일하게 선택해 다음 위치에 배치하는 과정을 반복합니다.

현대적인 제자리 방식은 배열의 뒤쪽부터 진행하며 현재 위치 이하의 임의 위치와 교환합니다. 각 단계의 선택이 균일하면 모든 순열의 확률이 같습니다. 원소 수에 비례하는 `O(n)` 시간이 필요합니다.

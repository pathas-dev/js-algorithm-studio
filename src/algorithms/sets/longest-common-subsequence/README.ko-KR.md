# 최장 공통 부분수열

[English](README.md) | [한국어](README.ko-KR.md)

두 수열에 공통으로 나타나는 가장 긴 부분수열을 찾습니다. 원소의 상대적인 순서는 유지하지만 원래 위치가 연속할 필요는 없습니다. 연속해야 하는 최장 공통 부분 문자열과 구분합니다.

`ABCDGH`와 `AEDFHR`의 답은 길이 3인 `ADH`이고, `AGGTAB`와 `GXTXAYB`의 답은 길이 4인 `GTAB`입니다. 데이터 차이를 비교하는 diff, 버전 관리의 변경 병합, 생물정보학 등에 활용됩니다.

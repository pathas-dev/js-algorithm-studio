# 버블 정렬

[English](README.md) | [한국어](README.ko-KR.md)

버블 정렬은 인접한 두 원소를 비교하고 순서가 잘못되어 있으면 서로 교환합니다. 배열을 한 번 훑으면 오름차순 기준으로 가장 큰 미확정 값이 뒤쪽에 자리 잡습니다. 이미 확정된 뒤쪽 구간은 다음 순회에서 제외할 수 있습니다.

한 번의 순회에서 교환이 없으면 배열 전체가 정렬된 상태이므로 바로 종료합니다. 비교와 교환을 반복하는 이유, 현재 비교하는 두 위치, 확정된 구간을 함께 보면 동작을 이해하기 쉽습니다.

조기 종료를 사용하는 경우 최선의 시간은 `O(n)`, 평균과 최악은 `O(n²)`입니다. 전형적인 제자리 구현의 추가 공간은 `O(1)`이며 같은 값을 교환하지 않으므로 안정 정렬입니다. 이 저장소 구현은 입력을 보존하기 위해 배열을 복사하므로 그 복사본에 `O(n)` 공간이 추가됩니다.

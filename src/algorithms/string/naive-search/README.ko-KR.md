# 단순 문자열 검색

[English](README.md) | [한국어](README.ko-KR.md)

패턴을 가능한 시작 위치마다 맞추고 왼쪽부터 한 글자씩 비교합니다. 불일치하면 패턴 전체를 한 위치 옮기고 비교를 다시 시작합니다. 처음 일치하는 인덱스를 반환하고, 없으면 `-1`입니다. 빈 패턴은 인덱스 `0`에서 일치합니다.

텍스트 길이가 `n`, 패턴 길이가 `m`이면 최악 시간은 `O(nm)`, 추가 공간은 `O(1)`입니다. 구현과 시각화는 JavaScript의 UTF-16 코드 단위와 인덱스를 사용하며 `String.indexOf`와 같습니다. 선택적 단계 콜백은 비교·이동을 기록하고 반환 결과는 바꾸지 않습니다.

# 해밍 거리

[English](README.md) | [한국어](README.ko-KR.md)

해밍 거리는 길이가 같은 두 문자열에서 대응하는 문자가 다른 위치의 수입니다. 한 문자열을 다른 문자열로 바꾸는 데 필요한 최소 치환 횟수로 볼 수 있습니다. 삽입과 삭제는 고려하지 않습니다.

`karolin`과 `kathrin`의 해밍 거리는 3이며 `1011101`과 `1001001`의 거리는 2입니다. 길이가 다른 입력에는 이 정의를 그대로 적용할 수 없습니다. 각 위치를 한 번 비교하므로 시간은 `O(n)`입니다.

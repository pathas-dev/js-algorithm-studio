# 트리

[English](README.md) | [한국어](README.ko-KR.md)

트리는 루트와 부모·자식 관계로 계층을 표현하는 자료 구조입니다. 각 노드는 값과 자식 참조들을 가지며, 루트에는 부모가 없습니다. 트리 안에서 부모·자식 링크가 사이클을 만들면 안 됩니다.

하위 트리도 같은 구조를 가지므로 재귀적으로 정의하고 탐색할 수 있습니다. 원문은 이진 탐색 트리, AVL 트리, 레드–블랙 트리, 세그먼트 트리, 펜윅 트리를 소개합니다. 이들은 검색, 균형 유지, 구간 집계 등 서로 다른 목적을 가집니다.

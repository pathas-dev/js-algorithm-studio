# 그래프

[English](README.md) | [한국어](README.ko-KR.md)

그래프는 정점들과 그 사이의 연결인 간선으로 구성됩니다. 무방향 그래프의 간선은 순서 없는 정점 쌍이고, 방향 그래프의 간선은 출발과 도착을 구분한 순서 있는 쌍입니다.

정점은 숫자 인덱스나 객체 참조로 표현할 수 있습니다. 간선에 거리·비용 같은 가중치를 추가할 수도 있습니다. 그래프는 트리보다 일반적인 연결 구조이며 사이클이나 여러 연결 요소가 있을 수 있습니다. 아래 그림과 참고 자료는 그래프의 개념과 표현 방식을 설명합니다.
